# Character and horror UX workflow
Use when developing entities, sprites, mutations, animation, lore and readability.
- Origin presets: Archivist/book, Radio Operator/receiver, Clockmaker/watch, Watchkeeper/lantern, Bellwraith.
- Bellwraith: warm as a human; once changed it can only repeat, as exact cited quotes from the evidence (echo voice). Never paraphrase an echo.
- Voice presets: regret, haunting, body, cosmic, monster, existential. Separate voice from artwork.
- Persist one numeric-repo-ID assignment with seed/config version. Preview silhouettes must not reroll identity.
- All three art states must share silhouette/object anchors; avoid runtime image generation.
- Entity is fictional: do not infer developer demographics or blame from GitHub data.
- Atmosphere can glitch; cited facts, quotes, paths, code, commands and accessibility plain text never glitch.
- Test missing assets, reduced motion, screen reader readable copy and responsive layout.
