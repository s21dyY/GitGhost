# Demo and release workflow
Use in stabilization/release phases, not every coding task.
- Re-run live feature flow and distinct labeled recorded fixture flow.
- Confirm real source citations, SHA isolation, valid brief, desktop/mobile and reduced motion.
- Confirm public GitHub repo, LICENSE, root `.kiro/`, README, safe example env and deployment access.
- Check no secrets/trademarks/unlicensed audio or art in public release.
- Video must be public YouTube, under 3 min, functioning app visible, Kiro contribution accurately demonstrated.
- Document concrete Kiro feature usage in KIRO_LOG.md with evidence of outcomes; no fabricated tests/pilot results.
- Make precise go/no-go list with defects, owner, reproduction steps and fixes.
