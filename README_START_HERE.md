# Start here
1. Read `BUILD.md` for the fresh project scope and implementation order.
2. Open this folder as a **new workspace** in Kiro after the Kiroween submission window opens.
3. Verify custom agent `gitghost-builder` is recognized and review its permissions. It intentionally has no broad auto-approval.
4. Use `github-evidence`, `ghost-character`, or `demo-readiness` skills only when relevant.
5. Paste section 13's first Kiro prompt. Instruct Kiro to implement M1 only.
6. Replace this starter README with actual local/deployment commands once the application exists.

The starter directory does not contain a Next.js app and is not meant to be deployed as-is. No APIs, cloud connections or credentials have been configured. Kiro's installed version may require adapting config syntax.
